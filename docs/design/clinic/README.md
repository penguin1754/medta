# 冷白诊室 · 落地说明（桌面 + 手机）

方案 A 已落到 Streamlit。本文件记录实际设计规则、手机端处理方式和验收数据。

## 1. 设计语言

| 项 | 取值 | 用途 |
| --- | --- | --- |
| 底色 | `#EDF2F3` | 冷灰工作台，带两处极淡的径向光 |
| 玻璃 | `rgba(255,255,255,.58)` + 24–32px 模糊 | 侧栏、指标块、问答卡 |
| 正文 | `#14262C` | 保证长文对比度 |
| 次级文字 | `#4D636B / #566C74` | 说明、标签（对底色对比度 5.6 / 4.9） |
| 主强调 | `#286A78` | 选中态、主按钮、进度 |
| 辅助 | `#86B9C3` | 渐变与细描边 |
| 警示 | `#A64038` | 答错、未通过 |

- 字体：系统无衬线栈（SF Pro / PingFang SC / Noto Sans SC），标题 52px（手机 40/34px），正文 15px（手机 14–14.5px）。
- 版面：桌面是 300px 浮动玻璃侧栏 + 最大 1120px 主区；页头左侧标题，右侧只放**本模块自己的**数据，不再五页共用同一组卡片。
- 玻璃只用于导航、指标和浮层，正文与判分结果仍在实色表面上。
- 动效集中在：页头进入、指标错峰、三维翻牌、判分印章、进度条与掌握度环；`prefers-reduced-motion` 下全部关闭。

## 2. 各页页头数据

| 页面 | 右侧内容 |
| --- | --- |
| 课程问答 | 「助教能回答」深色卡：概念 / 结构 / 损伤三行 + 出处说明 |
| 知识点速记 | 今日到期、已掌握 |
| 自测练习 | 已答题、正确率 |
| 考前冲刺 | 当前节奏（跟得上/偏紧）、日均需掌握 |
| 学习档案 | 最近 7 天有学习的天数、累计动作 |

## 3. 问答页

- 提问框不再是贴底的系统输入条，而是页头下方的内联玻璃卡（`st.chat_input` 放在容器里即为 inline 模式）。
- 卡片标题「直接输入问题」，下面一行说明，输入框 72–80px 高，聚焦时钢蓝描边。
- 示例问题做成整行卡片，带圆形「?」标记，手机上 56px 高；开始对话后自动收起，不再占地方。
- 提交后滚到最新一条回答；首轮问答在 390×844 下输入框和回答同屏，不需要滚动。
- 手机端隐藏右侧「助教能回答」卡，把首屏让给输入框（输入框在 844 高度内完整可见）。

## 4. 手机端规则

断点：`≤900px` 与 `≤520px`。

- 侧栏改成玻璃抽屉：宽度 `min(86vw, 360px)`，内容四周 8px，圆角 24px；展开时页面压暗一层，收起时 `visibility:hidden + pointer-events:none`。
- **选完导航自动收起**；点抽屉外的空白处或按 Esc 也会关。
- 左上角悬浮 44×44 玻璃按钮负责打开抽屉；抽屉内收起按钮同为 44×44，导航项 48px 高。
- 主区单列，内边距 68px / 66px。
- 页头：标题在上，指标两列 + 一行深色块，数值 26/24px。
- 快捷问题、章节筛选、题量：全部纵向整行，按钮最小高度 46px。
- 选择题选项做成整行卡片，最小高度 46px，选中态钢蓝描边。
- 知识卡：正面问题 25/22px，翻面高度 304/286px，圆角 24/22px。
- 冲刺：四个指标 2×2；未来几天排期横向滑动（卡片 140px，露出半张提示可滑），页面本身不横滚。
- 档案：五个指标 2×2；热力格 35 天，12–13px 一格。
- 勾选框 20px、日期/文本输入最小高度 44px。

## 5. 按钮

- 主按钮改成钢蓝渐变 `#2E7484 → #215C6A`，白字，对比度约 5.3:1。
- 修掉了按钮内 `<p>` 被全局正文色覆盖的问题（之前是深灰字压在深色底上），现在文字颜色继承按钮本身。
- 次按钮为白玻璃 + 深墨字，悬停提亮。

## 6. 验收数据（2026-11-09 实测）

视口：1440×960、390×844、360×800；Chrome + Playwright。

- 三个尺寸 `document.scrollWidth == innerWidth`，主区无横向溢出。
- 手机抽屉：390 宽时 335px、360 宽时 310px；收起按钮 44×44；导航项 48px 高；点导航后 `data-collapsed=true`。
- 点抽屉外空白、按 Esc 均能关闭。
- 问答页：390 宽下输入框 y≈359、高 72px，完整落在首屏；示例问题卡 56px 高。
- 选择题选项 46px 高；冲刺与档案指标 2×2（x = 12 / 200）。
- 交互回归 36/36 通过；`tools/test_new_features.py`、`tools/smoke_test.py` 全通过。
- 无文字截断、无页头与按钮重叠；`prefers-reduced-motion` 下动画为 `none`。

## 8. 已知取舍

- 冲刺排期在手机上是局部横向滚动，属有意设计；首屏不会整页横滑。
- 手机端问答页不显示「助教能回答」卡，能力说明压缩成输入框上方一行字。
- 对话变长后，提交新问题会把页面滚到最新回答，输入框随之上移；这是内联输入框的取舍。
