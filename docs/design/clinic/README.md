# 冷白诊室 · 落地说明（桌面 + 手机）

方案 A 已落到 Streamlit。本文件记录实际设计规则、手机端处理方式和验收数据。

## 1. 设计语言

| 项 | 取值 | 用途 |
| --- | --- | --- |
| 底色 | `#EDF2F3` | 冷灰工作台，带两处极淡的径向光 |
| 玻璃 | `rgba(255,255,255,.58)` + 24–32px 模糊 | 侧栏、指标块、工具条 |
| 正文 | `#14262C` | 保证长文对比度 |
| 次级文字 | `#4D636B / #566C74` | 说明、标签（对底色对比度 5.6 / 4.9） |
| 主强调 | `#286A78` | 选中态、主按钮、进度 |
| 辅助 | `#86B9C3` | 渐变与细描边 |
| 警示 | `#A64038` | 答错、未通过 |

- 字体：系统无衬线栈（SF Pro / PingFang SC / Noto Sans SC），标题 52px（手机 40/34px），正文 15px（手机 14–14.5px）。
- 版面：桌面是 300px 浮动玻璃侧栏 + 最大 1120px 主区；页头左侧标题、右侧三块不等权指标（第三块深色玻璃），不做等宽三卡。
- 玻璃只用于导航、指标和浮层，正文与判分结果仍在实色表面上。
- 动效集中在：页头进入、指标错峰、三维翻牌、判分印章、进度条与掌握度环；`prefers-reduced-motion` 下全部关闭。

## 2. 手机端规则

断点：`≤900px` 与 `≤520px`。

- 侧栏改成整屏玻璃抽屉：`100vw`，内容 8px 内边距，圆角 24px；收起时 `visibility:hidden + pointer-events:none`，不会挡住左上角的开抽屉按钮。
- 左上角悬浮 44×44 玻璃按钮负责打开抽屉；抽屉内收起按钮同为 44×44。
- 主区单列，内边距 68px / 66px，底部留 88–92px 给固定的聊天输入框。
- 页头：标题在上，三个指标变成「两列 + 一行深色块」，数值 26/24px。
- 快捷问题、章节筛选、题量：全部纵向整行，按钮最小高度 46px。
- 选择题选项做成整行卡片，最小高度 46px，选中态有钢蓝描边和浅底。
- 知识卡：正面问题 25/22px，翻面高度 304/286px，圆角 24/22px。
- 冲刺：四个指标排 2×2；未来几天排期改横向滑动（卡片 140px，露出半张提示可滑），页面本身不横向滚动。
- 档案：五个指标排 2×2；热力格 35 天，手机上 12–13px 一格。
- 勾选框 20px、日期/文本输入最小高度 44px。

## 3. 验收数据（2026-11-02 实测）

视口：1440×960、390×844、360×800；浏览器 Chrome，Playwright 驱动。

- 三个尺寸下 `document.scrollWidth == innerWidth`，主区无横向溢出。
- 手机抽屉：390 宽时内容 374px（左右各 8px），360 宽时 344px；收起按钮 44×44；导航项 48px 高。
- 选择题选项 46px 高；指标 2×2（x = 12 / 200）；排期条 `scrollWidth 584 > clientWidth 366`。
- 交互回归 36/36 通过：翻牌正反面、选择题判分、简答判分与要点 chips、冲刺指标、档案环与热力格、抽屉开合。
- 逻辑回归：`tools/test_new_features.py` 全通过；`tools/smoke_test.py` 全通过。
- 首屏自动滚到底部的问题已修：进入页面和切换模块时回到页首，同页答题/翻卡不强制滚动。
- 无文字截断、无页头与按钮重叠；`prefers-reduced-motion` 下动画为 `none`。

## 5. 已知取舍

- 冲刺排期在手机上是局部横向滚动，这是有意为之；首屏不会出现整页横滑。
- Streamlit 顶栏只保留「开/收侧栏」按钮，Deploy、主菜单、状态组件已隐藏。
- 首屏回顶通过一个 0 高度的 `components.html` 脚本实现，只在首次进入或切换模块时执行一次。
