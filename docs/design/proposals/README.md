# 三套视觉方向对比

这三张稿只比较视觉语言，不改现有功能。三张稿使用同一张知识卡、同一组学习数据和同一套导航，便于判断差异来自设计而不是文案。

## 共同原则

- 毛玻璃只放在导航、浮层和少量关键卡片上，正文仍然使用高对比表面。
- 每套只保留一个主强调色。错误、考试日期等状态色不参与大面积装饰。
- 动效只在翻卡、提交、换页、进度变化时出现，不做每个区块的淡入上浮。
- 不照搬 Apple 的图标、商标或专有字体，用系统字体栈和材质层级表达相近的质感。
- `prefers-reduced-motion` 下关闭所有动画。

## 方案 A：冷白诊室 / Clinic Glass

最接近“Apple 毛玻璃”的稳妥方向。浅冷灰底、骨白玻璃、手术钢蓝强调色，左侧是一块悬浮玻璃导航，右侧的考试倒计时使用深色玻璃，形成明确层级。

- 配色：`#EDF2F3` 底、`#FFFFFF` 玻璃、`#14262C` 正文、`#286A78` 主强调、`#86B9C3` 辅助。
- 字体：SF Pro / PingFang SC / Noto Sans SC 系统栈；标题 54px，知识卡问题 36px，正文 14–16px。
- 版面：浮动侧栏 + 非对称两栏；左侧一张大卡，右侧三块不同权重的数据块。
- 玻璃：侧栏和主卡使用 24–32px 模糊、1.4–1.55 饱和度、内侧 1px 高光；深色考试卡不再叠白色玻璃。
- 动效：主卡和统计块错峰上浮一次；按钮按压回弹；翻卡沿用现有三维翻转。
- 适合：课堂投影、答辩演示、白天长时间阅读。
- 风险：浅色玻璃对背景层次要求高，背景太空会像普通白卡片；需要保留解剖轮廓或冷光层次。

## 方案 B：夜间阅片室 / Reading Room

最“贵”的方向。深石墨底、冷蓝玻璃、暖琥珀只用于考试日期。顶部是悬浮玻璃导航，中间是一张 526px 高的深色知识卡，底部是玻璃进度坞。

- 配色：`#070C10` 底、`#132129` 玻璃、`#ECF3F5` 正文、`#9ECFDB` 冷光、`#D8A46D` 考试提示。
- 字体：SF Pro / PingFang SC 系统栈；主标题 66px / 650，倒计时 94px / 230，知识卡问题 40px。
- 版面：顶部导航 + 左右分栏 + 底部居中的进度坞；左侧是文字节奏，右侧是唯一的大玻璃卡。
- 玻璃：32–38px 模糊、低透明度、细边框和顶部高光；背景有一次很弱的冷光，不使用大面积彩色渐变。
- 动效：知识卡进入时上浮一次；按钮 hover 只提亮 4%；翻卡和判分保持现有动作。
- 适合：晚上复习、比赛现场大屏、想做出“这不是普通课程网站”的第一印象。
- 风险：深色长文阅读疲劳；教室投影亮度不足时，正文和次要信息可能发灰；需要准备浅色回退。

## 方案 C：解剖图谱台 / Atlas Vitrine

辨识度最高的方向。把知识卡做成一张图谱展板，而不是一张圆角卡片；左侧竖排索引，右侧是肝门静脉汇合示意图，只有右下角一块真正的玻璃数据浮层。

- 配色：`#E9EFF0` 冷灰底、`#F9FBFA` 图谱纸面、`#162528` 墨色、`#9F3B34` 标注红、`#3F707C` 静脉蓝。
- 字体：宋体 / Noto Serif SC 用于“肝门静脉”和大标题，界面文字使用系统无衬线；知识术语 68px，问题 21px。
- 版面：146px 竖排索引 + 单张图谱展板 + 底部进度细线；没有重复的等距卡片。
- 玻璃：只出现在右下角的今日数据浮层和左侧索引栏；主体是纸面，保证长文和图示清晰。
- 动效：展板进入时轻微上移；翻面后图谱标注线依次画出；考试进入 7 天内才让倒计时出现一次脉冲。
- 适合：想突出医学专业身份、答辩时让评委一眼记住、需要和普通聊天机器人拉开差距。
- 风险：竖排导航需要用户适应；宋体和红色标注容易让人联想到旧的“米色 + 宋体 + 赤陶”方案，必须靠冷灰底、图谱排版和更克制的红色来区分。

## 建议

如果目标是稳妥拿奖、现场演示、三个人都能维护，优先选 A。它最接近你说的 Apple 质感，也最容易从现有 Streamlit 页面迁移。

如果想让评委第一眼觉得“高级”，选 B，但一定要保留浅色回退，并把长文页面单独处理。

如果想让作品有唯一的医学识别度，选 C。它不是普通后台换皮，知识卡本身就是解剖图谱的一部分。

我实际最推荐 **A 的材质 + C 的解剖图谱细节**：用 A 的冷白玻璃和清晰层级做框架，在知识卡里加入 C 的静脉汇合示意图和少量标注红。这样既有 Apple 的轻和透，又不会变成任何学科都能套用的模板。

## 开源实现调研

只考虑许可证清晰、仍在维护的实现：

- `rdev/liquid-glass-react`：MIT，约 6.5k stars，React 组件；最近推送 2025-06-13。适合 React 项目，不适合直接塞进 Streamlit。
- `shuding/liquid-glass`：MIT，约 1.2k stars，SVG/着色器思路；最近推送 2026-03-26。可用于理解折射和高光，但 WebGL/SVG 位移会增加兼容和性能成本。
- `dashersw/liquid-glass-js`：MIT，约 1.6k stars，JavaScript 运行时；最近推送 2025-06-12。需要额外依赖，对当前页面收益不大。

结论：这次不引入第三方玻璃运行时。用 CSS `backdrop-filter` + 分层高光 + 细边框实现，兼容性和 Streamlit 集成成本更低；只在支持 `backdrop-filter` 的浏览器启用模糊，其他浏览器回退为半透明实色。
