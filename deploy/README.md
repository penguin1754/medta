# 让别人也能用这个网站

## 这套东西的结构（决定了怎么发布）

一个 Python 进程同时提供网页和接口：

- 网页：`frontend/index.html`（单文件，CSS/JS 都在里面）
- 接口：`/api/ask`、`/api/cards`、`/api/quiz`、`/api/profile` 等
- 数据：`db/progress.db`（SQLite，每个浏览器一个匿名 sid）
- 依赖：**只用 Python 标准库**，不需要 pip install

所以"发布"本质就是：让一台常开的机器跑起这个进程，别人能访问到它。

---

## 方案 A：同一 WiFi 直连（现在就能试，零成本）

双击 `start_lan.cmd`，窗口里会打印形如 `http://10.179.70.198:8787` 的地址，
同网段的手机/电脑用浏览器打开即可。

注意三件事：

1. Windows 第一次会弹防火墙提示，要允许"专用网络"，否则别人连不上。
2. **校园网经常做了客户端隔离**，同校不同设备可能互相访问不到。这种情况下改用手机开热点，
   让电脑和手机都连这个热点，最稳。
3. 只在同一网络内有效，离开这个 WiFi 就打不开，也发不给外地的评委。

适用：组内演示、答辩现场用同一台路由器时兜底。

### 别人打不开时，按这个顺序查

1. **确认服务是对外监听的**：窗口里应该打印"已对外监听"。命令行自查：
   `netstat -ano | findstr :8787`，看到 `0.0.0.0:8787` 才算对；
   如果只有 `127.0.0.1:8787`，说明你启动的是 `start_demo.cmd`，不是 `start_lan.cmd`。
2. **放行防火墙**（管理员 PowerShell 执行一次即可，端口换掉数字就换规则）：
   ```
   netsh advfirewall firewall add rule name="MedTA 8787" dir=in action=allow protocol=TCP localport=8787
   ```
3. **换手机热点**：校园网/图书馆 WiFi 常开客户端隔离，同一 WiFi 下两台设备互相看不见。
   用手机开热点，电脑连上去再跑 `start_lan.cmd`，成功率最高。注意 IP 会变，重新看窗口里的地址。

## 方案 B：内网穿透，临时给个公网链接（几十分钟能上线）

本机不用公网 IP，靠第三方隧道把 8787 暴露成 https 链接。

以 ngrok 为例（它的下载地址我这边实测可达）：

1. 注册 ngrok 账号，拿到 authtoken。
2. 下载 Windows 版并解压，然后：
   ```
   ngrok config add-authtoken <你的token>
   ngrok http 8787
   ```
3. 窗口里会给一个 `https://xxxx.ngrok-free.app` 的地址，发给谁都能打开。

要注意：

- 免费版域名每次重启都会变，**答辩当天要重新取链接并更新申报表/二维码**。
- 免费版有连接数和带宽限制，多人同时用会慢。
- 你的电脑必须一直开着、不休眠、不锁屏休眠网络。
- 国内访问 ngrok 的线路时快时慢，重要场合建议提前一天实测。

同类工具：花生壳（国内，速度较稳，免费版有限制）、frp（需要自己有服务器）。

## 方案 C：一台国内云服务器（推荐用于正式提交）

评委在国内，访问速度和稳定性都最好；服务器 7×24 开着，不依赖你的笔记本。

1. 买一台轻量应用服务器（腾讯云/阿里云，2 核 2G 起，学生机或新用户试用都行），
   系统选 Ubuntu 22.04。
2. 安全组/防火墙放行 **8787** 端口。
3. 把整个 `medta` 文件夹传上去（`.env` 和 `db/` 可以不传）。
4. 启动：
   ```
   cd medta
   python3 backend/app.py --host 0.0.0.0 --port 8787
   ```
5. 别人访问 `http://服务器公网IP:8787`。

想让它关掉终端也不停，用 systemd（`/etc/systemd/system/medta.service`）：

```
[Unit]
Description=MedTA
After=network.target

[Service]
WorkingDirectory=/root/medta
ExecStart=/usr/bin/python3 backend/app.py --host 0.0.0.0 --port 8787
Restart=always

[Install]
WantedBy=multi-user.target
```

然后 `systemctl enable --now medta`。

关于备案：国内服务器上用**域名**走 80/443 需要 ICP 备案；用 **IP + 非标准端口（如 8787）**
通常可以直接访问，不需要备案。这是一般经验，不是法规保证，正式对外还是以学校/云厂商要求为准。

## 方案 D：静态托管（不推荐）

Gitee Pages / GitHub Pages / 各种静态托管只能放网页，不能跑 Python。
而间隔重复、判分、学习档案全在后端，静态托管等于把这些功能砍掉。
除非专门做一个"纯前端演示版"，否则不要走这条。

## 上线前必须处理的四件事

1. **Coze 额度**：填了 `COZE_PAT` 后默认全站 100 次、每个浏览器每天 10 次，
   同一问题命中缓存不再扣次数，到顶自动回落本地知识卡。公开给全班前先按人数算一下：
   100 次 ÷ 每人 10 次 = 最多 10 个活跃用户，人更多就把 `COZE_PER_USER` 调低。
   令牌只放服务器 `.env`，不要写进网页或小程序。
2. **访问控制**：现在没有密码，拿到链接的人都能用（每人只影响自己的 sid，不会看到别人的记录）。
   如果只想给评委看，可以加一个简单的访问口令。
3. **数据**：记录在 `db/progress.db`，重启不丢；但重装系统就没了，重要演示前备份一份。
4. **兜底**：现场网络不可控，准备一段 2 分钟录屏，评委那边打不开时直接放。
